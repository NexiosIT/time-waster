# Heckler Implementation Plan

> Executed inline (small change). Steps use checkbox syntax.

**Goal:** passive-aggressive lines during play and at run end, toggled with H.
**Spec:** `docs/superpowers/specs/2026-11-20-heckler-design.md`

## Global Constraints

- Arcade has no runtime deps; never pauses a game or consumes keys; Claude banner wins row 0.
- Show 6 s; min gap 20 s; checkpoints every 45 s of play; stuck = 45 s without score change; behind = score < 0.6 × best × min(1, played/expected) (expected unknown → best × 0.5).
- Swears: mild only (damn, hell, shit, crap), ~1 in 4 lines; performance only.

## Review Focus

1. Pausing: play time (session.playedMs) must not advance checkpoints while paused.
2. Claude banner showing: heckle never drawn over it.
3. Heckling off: nothing drawn, results line absent.
4. Corrupt/missing settings.json: defaults to on, no crash.
5. Very long game titles/scores in templates: clipped to the row width.

### Task 1: lines + Heckler engine
- Create `src/core/heckles.ts` (template lists `BEHIND`, `STUCK`, `NO_BEST`, `RUN_WORSE`, `RUN_BEST`, `fill(template, vars)`), `src/core/heckler.ts`:
  `class Heckler { constructor(rnd: () => number); startRun(): void; tick(i: { nowMs; playedMs; score; best: number | null; expectedMs: number | null; game: string }): void; current(nowMs): string | null; runOver(i: { score; best: number | null; isBest: boolean; game: string }): string }`
- Tests `src/core/heckler.test.ts`: behind-pace fires at 45 s checkpoint and not when on pace; stuck fires after 45 s unchanged; no-best generic; 20 s gap; 6 s display; paused (playedMs frozen) never fires; runOver picks RUN_BEST on new best and fills score/best; every template fills without leftover `{`; swear share ≥ 1 in 5 and only from the allowed words.

### Task 2: settings + App wiring
- `src/core/settings.ts` (`loadSettings(file): { heckle: boolean }`, `saveSettings(file, s)` via jsonfile), `paths.settingsFile()`.
- `App`: option `settingsFile?`; `H` in menu toggles + saves; menu row 18 `H: heckling on|off`; `tick` feeds the heckler; `render` draws the line on row 0 only when no full banner; results row 16 shows the run-over line when on.
- Tests in `app.test.ts`: toggle and persistence; line on row 0 when behind; banner wins; off → nothing; results line; corrupt settings → on.
- `arcade.ts` passes `settingsFile()`. README: one line in Keys and data files.

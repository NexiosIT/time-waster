# Play in the Browser Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The server container lets anyone play every bundled game in the browser and save a score under a typed name on a separate per-game Web board.

**Architecture:** A browser bundle (`server/web/`) runs the arcade's own `GameSession` and renders its 60 x 20 `CellBuffer` as coloured text. The server gains a `web_best` table (schema v2), two JSON endpoints, a `/play/<id>` page with its own CSP, a static `/assets/play.js`, and a Web top 10 on each game page. Pure logic (keys, grid rendering, the play state machine, validation, DB) is unit-tested in Node; the DOM glue is thin and checked end to end with the pre-installed Playwright Chromium.

**Tech Stack:** TypeScript, Node 24 `node:http` + `node:sqlite`, esbuild, vitest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-20-web-play-design.md`

## Global Constraints

- No npm runtime dependencies; no new devDependencies.
- Existing pages keep exactly today's CSP (`default-src 'none'; style-src 'unsafe-inline'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`). Only `/play/<id>` adds `script-src 'self'; connect-src 'self'`. No inline scripts anywhere.
- Web names never appear on the Arcade board, in `/v1/boards*`, or anywhere the terminal arcade reads. `DELETE /v1/me` and `delete-player` don't touch `web_best`.
- Name: trimmed, inner whitespace collapsed to one space, 1–20 characters from letters (Unicode `\p{L}`), digits, space, `_ - .`; `name_key` = lower-cased name.
- Score: integer `0..maxScoreFor(game)`; `game` must be a bundled game (`knownGames()`).
- Rate limits (429): 30 web posts per IP per hour (only when `trustProxy`), 600 per hour globally.
- One row per (game, name_key) holding that name's best: higher score replaces score, `at` and display casing; equal or lower leaves the row, still counts in `submissions`. Response 200 `{ rank: number | null, best: number, top: WebRow[] }`; `rank` = position of the name's best in the web top 10, else null.
- Browser keys from `event.key` → the terminal's `Key` names; keys with Ctrl/Alt/Meta held are ignored. The game sees no keys while the name input has focus.
- `src/core/session.ts` and the games are not changed. `dist/` is never committed on this branch.

## Review Focus

1. **Typing a name containing game keys (p, space, arrows) after a run:** nothing reaches the game; the name field gets the characters. Test in Task 3 (controller ignores keys in `results` while `nameFocused`).
2. **Posting the same name with different casing / spacing (`" Kim  B "`, `"kim b"`):** one row, `name_key` `kim b`; display casing from the best score. Test in Task 1.
3. **`/play/<unknown>` or `/play/../x`:** the existing 404 page; no script served. Test in Task 4.
4. **Hidden tab during a run, then back:** paused while hidden, resumed on return; a run the player paused stays paused. Test in Task 3.
5. **Old database at schema v1 with existing scores:** upgrades in place to v2, arcade scores intact. Test in Task 1.

### Task 3: Browser play logic

**Files:** Create `server/web/keys.ts`, `server/web/grid.ts`, `server/web/controller.ts`; Tests `server/web/keys.test.ts`, `server/web/grid.test.ts`, `server/web/controller.test.ts` (confirm `vitest.config.mts` picks up `server/web/**/*.test.ts`; widen its include if not)

**Interfaces:**
- `keyFromEvent(e: { key: string; ctrlKey: boolean; altKey: boolean; metaKey: boolean }): Key | null` — `ArrowUp/Down/Left/Right` → `up/down/left/right`, `' '` → `space`, `Enter` → `enter`, `Escape` → `escape`, `Backspace` → `backspace`, `Tab` → `tab`, any single character → lower-cased; modifiers held or anything else → null.
- `gridLines(buf: CellBuffer): string[]` — one HTML string per row: runs of same-coloured cells as `<span class="c-<color>">…</span>` with `&<>` escaped; `COLOR_CLASSES` lists the 16 `Color` names.
- `class PlayController` constructed with `{ game: Game<any>, nowMs: number, seed: () => number, loadBest(): number | null, saveBest(n: number): void }`; `state: 'ready' | 'playing' | 'results' | 'crashed'`; `key(k: Key, nowMs): void`; `tick(nowMs): void`; `frame(): CellBuffer` (60 x 20, the session's draw while playing, else the last frame); `status(): string` (`<Title>  Score N  Your best B  <controls>  P pause · Esc end`, or the ready / results prompt); `setHidden(hidden: boolean, nowMs)`; `nameFocused: boolean`; `result: { score: number; isBest: boolean } | null`; `onExit?: () => void` (Esc in results).
- Rules: `ready` + Enter → new `GameSession(game, { seed: seed(), nowMs })` → `playing`; while playing keys go to `session.key`; `session.status` `over` → `results` with `isBest` = beats `loadBest()` (then `saveBest`); `crashed` → `crashed`, Enter restarts; in `results` (when not `nameFocused`) Enter → new run, Esc → `onExit`; any key while `nameFocused` is ignored (Review Focus 1). `setHidden(true)` sends `p` only if the session is `playing` and remembers it; `setHidden(false)` sends `p` only if it paused it (Review Focus 4).

### Task 4: Play page, assets and boards

**Files:** Create `server/web/main.ts` (DOM glue); Modify `scripts/build-server.mjs`, `server/src/pages.ts`, `server/src/http.ts`, `server/src/main.ts`; Test `server/src/pages.test.ts`, `server/src/http.test.ts`

**Interfaces:**
- Consumes: Tasks 2–3.
- `main.ts`: reads the game id from `document.body.dataset.game`; finds the game in `src/games/registry.generated`; creates a `PlayController`; renders `gridLines` into `<pre id="grid">` (only changed lines), status into `#status`; `requestAnimationFrame` loop calling `tick(performance.now())`; `keydown` → `keyFromEvent` → `preventDefault()` for arrows, space, Enter, Escape, Tab, Backspace when the key went to the controller; `visibilitychange` → `setHidden`; name form `#save` (input `#name` with `localStorage['tw-name']`, focus/blur set `nameFocused`) posts to `/v1/web-scores`, shows `Saved` or the server error, disables the form after success, and re-renders `#web-board` from the response's `top`; `localStorage['tw-best-<id>']` for `loadBest`/`saveBest`; every storage access wrapped in try/catch; `onExit` → `location.href = '/games/<id>'`.
- `build-server.mjs`: first build `server/web/main.ts` → `server/dist/public/play.js` (`platform: 'browser'`, `format: 'iife'`, `minify: true`, `target: 'es2022'`), sha256 the output, take the first 12 hex chars as `PLAY_JS_HASH`, then build the server with `define: { PLAY_JS_HASH: JSON.stringify(hash) }` (declare `const PLAY_JS_HASH: string` for TypeScript; tests use a fallback `'dev'` when undefined).
- `pages.ts`: `renderPlay(game: GameInfo, webTop: WebRow[]): string` — body `data-game="<id>"`, grid `<pre id="grid">`, `#status`, hidden-until-results name form, `#web-board`, link back to `/games/<id>`, `<script src="/assets/play.js?v=<hash>" defer></script>`; `renderIndex` adds `▶ Play` (`/play/<id>`) per game; `renderBoard(game, top, webTop)` adds `▶ Play` and a second card `Web` top 10 (names escaped; "No web scores yet." when empty). CSS classes `.c-<color>` for the 16 colours in `STYLE`.
- `http.ts`: `send()` takes per-reply headers (`Reply.headers?`); `PLAY_HEADERS` = page headers with CSP `default-src 'none'; script-src 'self'; connect-src 'self'; style-src 'unsafe-inline'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`; `GET /play/<id>` (known game only, else 404 page — Review Focus 3); `GET /assets/play.js` → 200 `text/javascript; charset=utf-8`, `cache-control: public, max-age=31536000, immutable`, body read once at startup from `path.join(__dirname, 'public', 'play.js')` (missing file → 404, logged once); `HandlerDeps` gains optional `playJs?: string` so tests inject it.

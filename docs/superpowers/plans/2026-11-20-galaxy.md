# Galaxy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Galaxy, an original 5-wave fixed-shooter game, to the arcade as one new folder.

**Architecture:** `src/games/galaxy/` only. `waves.ts` holds the per-wave difficulty table,
`state.ts` holds plain-data state plus pure `init` / `onKey` / `step` rules, `draw.ts`
paints a state, and `index.ts` wires them into the `Game` contract. Time is counted in
ticks (one `update` = one tick of `tickMs` 50 ms), so the rules are deterministic.

**Tech Stack:** TypeScript, vitest, existing `Game` contract (`src/core/types.ts`).

**Spec:** `docs/superpowers/specs/2026-11-20-galaxy-design.md`

## Global Constraints

- Touch only `src/games/galaxy/` (plus this plan). No edits to `src/core/`, other games, `dist/`, `package.json`.
- Plain-data state; every function pure (return new state, never mutate input); randomness only via `ctx.random()`; no `Math.random()` / `Date.now()`.
- Single-width characters only; draw only inside 60 x 20 (`GAME_WIDTH`, `GAME_HEIGHT`).
- Press-only input; never bind `p`, Esc, Ctrl+C.
- Contract: `id 'galaxy'`, `title 'Galaxy'`, `length { kind: 'rounds', minutes: 3 }`, `maxScore 5200`, `tickMs 50`.
- Original look: enemies `<o>` drone 10 pts brightCyan, `{#}` brute 20 pts brightMagenta, `/V\` stinger 30 pts brightYellow; ship `/^\`; debris `▓`.
- 5 waves, 3 lives total, no extra lives; wave clear `+100 × lives left`; wave 5 clear `+500` and `GALAXY CLEARED`.
- `dist/` is never committed on this branch.

## Review Focus

1. **Space pressed while your shot is still flying:** ignored (one player shot at a time), no error. Test in Task 2.
2. **Ship at the left/right edge pressing outward:** stays fully on screen (x clamped to 0..57). Test in Task 2.
3. **Formation reaches row 17 while lives remain:** game over anyway. Test in Task 3.
4. **Keys pressed during the `GALAXY CLEARED` banner or after game over:** ignored, score unchanged. Test in Task 3.
5. **Formation at its far left/right and lowest position:** nothing drawn outside 60 x 20, HUD never overwritten by enemies. Test in Task 4.

### Task 2: State, ship and player shots

**Files:**
- Create: `src/games/galaxy/state.ts`
- Test: `src/games/galaxy/state.test.ts`

**Interfaces:**
- Consumes: `WAVES`, `marchInterval` (Task 1).
- Produces (all exported from `state.ts`):
  - constants `ROWS 4`, `COLS 8`, `CELL_W 4` (3 wide + 1 gap), `FORMATION_W 31`, `SHIP_Y 18`, `SHIP_W 3`, `DEBRIS_Y 16`, `LOSE_ROW 17`, `LIVES 3`, `POINTS = { drone: 10, brute: 20, stinger: 30 }`, `WAVE_BONUS 100`, `CLEAR_BONUS 500`, `BLINK_TICKS 20`, `BANNER_TICKS 40`, `ENEMY_SHOT_EVERY 2`
  - `type Kind = 'drone' | 'brute' | 'stinger'`; `kindOfRow(r: number): Kind` (row 0 drone, 1–2 brute, 3 stinger)
  - `type Point = { x: number; y: number }`
  - `type GalaxyState = { wave: number /* 1..5 */; lives: number; score: number; shipX: number; shot: Point | null; enemyShots: Point[]; alive: boolean[][] /* [ROWS][COLS] */; fx: number; fy: number; dir: 1 | -1; marchIn: number; tick: number; debris: Point[]; blink: number; banner: number; over: boolean }`
  - `enemyAt(s, r, c): Point` → `{ x: s.fx + c × CELL_W, y: s.fy + r }`
  - `initState(): GalaxyState` — wave 1, lives 3, score 0, `shipX 28`, `fx 14`, `fy WAVES[0].startRow`, `dir 1`, all alive, debris = 3 blocks of 4 cells on row 16 at x 10–13, 28–31, 46–49, `marchIn` = `marchInterval(WAVES[0], 32, 32)`.
  - `onKey(s, key): GalaxyState` — `left`/`right`: `shipX ∓/± 2` clamped to `0..57`; `space`: if `shot === null` set `shot = { x: shipX + 1, y: SHIP_Y − 1 }`; any key ignored when `over` or `banner > 0`.
  - `stepShot(s): GalaxyState` — moves the player shot up 1 row; removes it above row 1 (row 0 is the HUD); on reaching a debris cell removes that cell and the shot; on reaching an alive enemy's 3 cells (`x..x+2`, `y`) kills it, adds `POINTS[kindOfRow(r)]`, removes the shot.

### Task 3: Formation, enemy fire, lives and waves

**Files:**
- Modify: `src/games/galaxy/state.ts`
- Test: `src/games/galaxy/state.test.ts`

**Interfaces:**
- Consumes: Task 1 and Task 2 exports.
- Produces: `step(s: GalaxyState, random: () => number): GalaxyState` — one tick, in this order:
  1. If `over`: return `s`. If `banner > 0`: `banner − 1`; when it reaches 0 set `over = true`; return.
  2. `tick + 1`; `blink − 1` (not below 0); `stepShot`.
  3. Enemy shots move down 1 row every `ENEMY_SHOT_EVERY` ticks; a shot reaching a debris cell removes both; reaching the ship's cells (`shipX..shipX+2`, row 18) while `blink === 0`: `lives − 1`, `enemyShots = []`, `blink = BLINK_TICKS`; `lives === 0` → `over`; shots below row 19 vanish.
  4. Fire: if `enemyShots.length < spec.maxEnemyShots` and `random() < spec.fireChance`, pick a column with alive enemies by `Math.floor(random() × aliveColumns.length)`, fire from its lowest alive enemy at `{ x: ex + 1, y: ey + 1 }`.
  5. March: `marchIn − 1`; at 0, move `fx + dir`; if the formation's alive bounds would leave `0..59`, instead `fy + 1` and `dir = −dir`; reset `marchIn = marchInterval(spec, alive, 32)`. Alive bounds use the leftmost/rightmost alive columns, so a thinned formation reaches the walls.
  6. If any alive enemy row `≥ LOSE_ROW`: `over`.
  7. All enemies dead: `score + WAVE_BONUS × lives`; if `wave === 5`: `score + CLEAR_BONUS`, `banner = BANNER_TICKS`; else next wave: `wave + 1`, all alive, `fx 14`, `fy = startRow`, `dir 1`, debris rebuilt, `shot = null`, `enemyShots = []`.

- [ ] **Step 1: Write failing tests** (fixed seed via `createRandom`, or a stub `random` returning fixed values): `step` doesn't mutate; after `marchTicks` ticks the formation moved 1 column; at the right wall it drops a row and reverses; with only the far-right column alive it travels further right than a full formation; no enemy fire when `random` returns 0.99, a shot from the lowest enemy of the chosen column when it returns 0; never more than `maxEnemyShots` enemy shots; an enemy shot hitting the ship costs one life, clears enemy shots and starts the blink, and a second hit during the blink costs nothing; third life lost → `over`; formation forced to row 17 with 3 lives → `over` (Review Focus 3); killing the last enemy of wave 1 with 3 lives adds 300 and starts wave 2 at `startRow 3` with debris rebuilt; clearing wave 5 adds `300 + 500`, sets `banner`, and `over` only after `BANNER_TICKS` ticks; keys during the banner and after `over` change nothing (Review Focus 4).
- [ ] **Step 2: Run — expect FAIL.**
- [ ] **Step 3: Implement.**
- [ ] **Step 4: Run — expect PASS.**
